# Независимая оценка решения

Пакеты находятся в `.private/review-ready`, исключены из Git и не публикуются на сайте. Все оценки изначально пустые. Материалы передаются только согласованным оценщикам в рамках условий кейса; удаление — не позднее 4 декабря 2026 года.

## Черновики

Откройте `blind-review.html`. В нём 100 обращений с вариантами A и B: один подготовлен системой, второй — исходный ответ администратора. Порядок скрыт и перемешан. Оценщик вводит своё имя или код, оценивает оба варианта по шкале 1–5 и скачивает JSON. Файл `blind-key.json` оценщику передавать нельзя. После получения заполненного файла выполните:

```sh
node scripts/score-reviews.mjs path/to/blind-100-rated.json blind
```

## Языки

Носители kk/uz открывают `native-review.html`: 32 примера на каждом языке. Поля оценивают естественность языка, полезность и привязку к основанию. Проверки cp1251 и смешанной речи дополнительно выполняются синтетическими тестами; они не заменяют оценки носителей. Заполненный JSON обрабатывается командой:

```sh
node scripts/score-reviews.mjs path/to/native-review-rated.json native
```

## Разметка классификации

`label-review.html` содержит 120 зафиксированных обращений без предсказаний системы и административных исходов. Эксперт выбирает категорию, приоритет и язык. Хэши исходного набора и файлов зафиксированы в `manifest.json`. Не меняйте набор после получения оценки и не используйте контрольные метки для настройки.

```sh
node scripts/score-reviews.mjs path/to/independent-labels-rated.json labels
node scripts/evaluate.mjs .private/independent-labelled.jsonl .private/independent-metrics.json
```

Файл с метками создаётся только при полной разметке допустимыми значениями. Реальная выборка может не содержать p0: это следует честно указать. Отдельный авторский синтетический набор из 24 сценариев покрывает шесть языков и p0–p3, но независимым контрольным набором не является.

Ни наличие заполненного имени, ни выполнение скрипта не доказывают экспертность и независимость оценщика. Эти сведения подтверждает команда. Официальную слепую оценку и скрытый тест проводит жюри.

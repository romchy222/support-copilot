# Grand Support Copilot

Автономный HTTP-сервис и рабочее место администратора для кейса 03 Decentrathon 6.0.

## Запуск

Требуется Node.js 22.13+ и Python 3 для подготовки архива. Из этой папки:

```sh
npm ci
python scripts/prepare-data.py ../Данные/grand-support-copilot-handout-2026-10-27.tgz
npm run dev -- --host 127.0.0.1 --port 4173
```

Открыть `http://127.0.0.1:4173`. Локальное R2-хранилище и опубликованное R2 различаются. Веб-сервис получает корпус через защищённый `POST /api/corpus`; локальный пакетный запуск читает `.private/corpus.json`. Инструкция импорта и Gemini — в [GEMINI_SETUP.md](GEMINI_SETUP.md). Отсутствующий корпус отображается как ошибка конфигурации с безопасным резервным ответом.

## Обработка

`POST /triage`, `Content-Type: application/json`:

```json
{"kind":"complaint","messages":[{"role":"player","text":"Игрок оскорбляет меня в чате, сервер 4","attachments":2}]}
```

Возвращает поля ТЗ: `lang`, `category`, `priority`, `is_spam_or_duplicate`, `extracted`, `draft_reply`, `needs_human`, `confidence`, `reasons`; дополнительно `analysis` и `latency_ms`. Цитаты представлены как `Общие правила игры § 2.1`, поскольку номер повторяется в разных разделах. Уникальные идентификаторы фрагментов и первоисточники находятся в `analysis.cited_sources`.

Поддерживается исходная схема датасета: `images_count`, `reported_nick`, `rule_refs_raw`, `reporter_hash`, `reported_hash`, `created_at`, `server`. Сообщения `admin`, вердикты и наказания исключаются до анализа. Указанный игроком пункт не считается истинным. Вложения не просматриваются.

RAG: BM25 с игровыми синонимами, все 11 разделов правил, 280 фрагментов. Gemini 3.5 Flash-Lite получает top-4. На выходе проверяются схема, категория канала, ссылки, дословные цитаты и опасные обещания. Правила и шаблоны не доказывают факт нарушения. Проверка цитат не заменяет смысловую оценку человеком.

Платежи, аккаунты, апелляции и жалобы на администрацию передаются человеку независимо от решения модели. Автоматические ответы разрешаются только для безопасного уточнения или подтверждённой инструкции при достаточной оценке; оценка уверенности не калибрована.

## Приватность и Gemini Free

Ввод без `data_mode:"synthetic"` обрабатывается локально и не передаётся Google. Gemini Free вызывается только для отмеченных синтетических примеров. API-ключ хранится как секрет сервера и в игнорируемом `.env.local`. Данные хакатона и производные выборки не публикуются.

Бесплатная квота зависит от проекта Google. Нельзя определить тариф по ключу; автоматического перехода на платную модель нет. Возвращаются токены и оценка стандартной платной стоимости, а фактический счёт не выдумывается. При таймауте неизвестно, успел ли провайдер начислить токены. [Условия Google](https://ai.google.dev/gemini-api/terms), [тарифы](https://ai.google.dev/gemini-api/docs/pricing).

## Очередь и обратная связь

Обращения, черновики, решения и предыдущие версии текста хранятся в приватном R2. Правки переживают перезагрузку страницы. Конкурирующие записи защищены ETag и версией; при конфликте нужно обновить очередь. Подтверждение требует явной проверки администратором. Кнопка не отправляет сообщение в игру: боевые API по ТЗ отсутствуют.

`GET/POST /api/tickets`, `POST /api/tickets/:id` — очередь и действия `save`, `approve`, `escalate`, `reopen`. История сохраняет исходный и исправленный текст как обучающий сигнал. После трёх подтверждённых ответов одной категории интерфейс предлагает кандидата в шаблоны; это группировка по категории, а не обученный семантический кластеризатор.

Для дедупликации необходимы анонимный ID заявителя и время: одна проблема, один игрок, окно один час, сходство токенов ≥ 0.75. Онлайн-контекст хранит до 100 обращений на игрока за последний час обработки; пакетный режим использует последние 10 000 записей. Это ограничение памяти, а не обещание полной исторической дедупликации.

## Пакетный запуск и оценка

```sh
make predict IN=.private/tickets_valid.jsonl OUT=.private/pred-valid.jsonl
# Если make отсутствует:
node scripts/predict.mjs .private/tickets_valid.jsonl .private/pred-valid.jsonl
npm test
npm run typecheck
node scripts/evaluate.mjs .private/tickets_valid.jsonl .private/evaluation-valid.json
node scripts/create-review-set.mjs
```

Одна строка входа соответствует одной строке выхода. Ошибочная запись возвращает `line` и `error`, завершение — с ненулевым кодом. Вход и выход не могут быть одним файлом. Для категории/приоритета метрики считаются только при наличии независимых меток; предоставленная валидация их не содержит. Подготовлена приватная выборка из 100 обращений для ручной разметки без ответов администраторов. Живой smoke-тест на синтетике: `node scripts/smoke-live.mjs`.

Результаты и ограничения — в [REPORT.md](REPORT.md). Данные нужно удалить в течение 14 дней после объявления победителей, если нет отдельного соглашения. Это относится к `.private`, выгрузкам, резервным копиям и загруженному корпусу; дата объявления победителей пока не задана.

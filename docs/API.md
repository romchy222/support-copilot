# API Grand Support Copilot

← [README](../README.md) · [Архитектура](ARCHITECTURE.md) · [Соответствие ТЗ](TZ-COMPLIANCE.md)

Базовый адрес локально — `http://127.0.0.1:4173`. Все ответы — `application/json; charset=utf-8`; ответы API не кэшируются (`Cache-Control: no-store`).

## Маршруты

| Метод и путь | Назначение | Доступ |
| --- | --- | --- |
| `POST /triage` | триаж одного обращения по контракту ТЗ | открыт на уровне приложения |
| `GET /api/tickets` | страница очереди (по 50, курсор) | чтение |
| `POST /api/tickets` | создать обращение, выполнить триаж и сохранить | требует вход администратора |
| `POST /api/tickets/{id}` | действие над обращением: `save`, `approve`, `escalate`, `reopen`, `send_test` | требует вход администратора |
| `POST /api/test-delivery` | тестовая «отправка» подтверждённого ответа с квитанцией | требует вход администратора |
| `GET /api/knowledge?q=&section=` | поиск и просмотр базы правил | чтение |
| `GET /api/corpus` | статус корпуса и модели | чтение, без секретов |
| `POST /api/corpus` | импорт корпуса правил в R2 | секретный заголовок `x-rag-admin-token` |

> [!NOTE]
> Для изменяющих маршрутов платформа передаёт заголовки аутентифицированного пользователя; без них сервис отвечает `401`. Каждое событие в истории обращения сохраняет автора. Опубликованный сайт с материалами кейса закрыт для публики, на нём действуют и правила платформы.

## `POST /triage`

### Запрос

`Content-Type: application/json`, тело ≤ 100 КБ, чтение ≤ 400 мс.

```json
{
  "kind": "complaint",
  "messages": [
    { "role": "player", "text": "Arman_Petrov оскорблял меня и мою семью в чате, скрины есть, 2.1 ОП", "attachments": 2 }
  ]
}
```

| Поле | Тип | Обязательно | Описание |
| --- | --- | :---: | --- |
| `kind` | `"complaint"` \| `"report"` | да | канал: жалоба из лаунчера или репорт из игры |
| `messages` | массив, 1–50 | да | суммарно ≤ 20 000 символов |
| `messages[].role` | `player` \| `reported_player` \| `admin` | да | сообщения `admin` **отбрасываются** |
| `messages[].text` | строка | да | хотя бы одно непустое сообщение `player` |
| `messages[].attachments` | целое 0–100 | нет | число вложений (содержимое сервис не получает) |
| `images_count` | целое 0–100 | нет | схема датасета; если вложений в сообщениях нет, переносится на первое сообщение игрока |
| `ticket_id`, `reported_nick`, `rule_refs_raw`, `region`, `server_lang`, `reporter_hash`, `reported_hash`, `server` | строка ≤ 256 | нет | служебные поля датасета |
| `created_at` | ISO-8601 | нет | время; без часового пояса считается UTC |
| `data_mode` | `"synthetic"` \| иное | нет | `synthetic` разрешает внешний вызов модели; по умолчанию `private` |

Поля `verdict`, `punishment`, `violation`, `category`, `priority` и любые сообщения роли `admin` в конвейер **не попадают**.

> [!TIP]
> Для дедупликации «один игрок · одна проблема · час» передавайте `reporter_hash` и `created_at`: в минимальном примере ТЗ этих полей нет, и без них сервис честно сообщает `dedup_checked: false`.

### Ответ `200`

```json
{
  "lang": "ru",
  "category": "complaint.insult",
  "priority": "p1",
  "is_spam_or_duplicate": false,
  "extracted": {
    "nickname": "Arman_Petrov",
    "rule_refs": ["2.1"],
    "has_evidence": true,
    "server": "4"
  },
  "draft_reply": {
    "lang": "ru",
    "text": "Здравствуйте! Пункт 2.1 общих правил запрещает оскорбления игроков и их родственников. Приложенные материалы и обстоятельства должен проверить администратор. Уточните время события.",
    "cited": ["2.1"]
  },
  "needs_human": true,
  "confidence": 0.95,
  "reasons": ["Нужно проверить обстоятельства и черновик ответа"],
  "analysis": { "...": "см. ниже" },
  "latency_ms": 1823
}
```

| Поле | Тип | Значения и смысл |
| --- | --- | --- |
| `lang` | строка | `ru`, `kk`, `uz`, `en`, `es`, `pt`, `und` |
| `category` | строка | одна из 14 категорий таксономии |
| `priority` | строка | `p0` критично, `p1` высокий, `p2` обычный, `p3` низкий |
| `is_spam_or_duplicate` | bool | пустое сообщение или повтор того же игрока в течение часа |
| `extracted.nickname` | строка \| `null` | ник обвиняемого (из `reported_nick` или найденный в тексте) |
| `extracted.rule_refs` | массив строк | **короткие номера** проверенных пунктов (`"2.1"`), не пункты, названные игроком |
| `extracted.has_evidence` | bool | указано ли хотя бы одно вложение; содержимое **не проверено** |
| `extracted.server` | строка \| `null` | сервер из поля или текста |
| `draft_reply.lang` | строка | язык черновика; для `und` — `ru` |
| `draft_reply.text` | строка | текст без обещаний наказания, разбана, возврата и без утверждений о просмотре вложений |
| `draft_reply.cited` | массив строк | короткие номера цитируемых пунктов (без `§`) |
| `needs_human` | bool | `true` — ответ без проверки отправлять нельзя |
| `confidence` | число 0–1 | **самооценка или эвристика**, не калиброванная вероятность |
| `reasons` | массив строк | причины решения, в том числе обязательной эскалации |
| `latency_ms` | целое | время обработки на сервере |

#### Поле `analysis` (расширение сверх ТЗ)

| Поле | Описание |
| --- | --- |
| `category_title` | человекочитаемое название категории |
| `qualified_citations` | однозначные ссылки `Раздел § Пункт` — номера повторяются между разделами |
| `cited_sources` | полные источники: `id`, `ref`, `section`, `title`, `text`, `score`, `overlap` |
| `retrieved` | что нашёл RAG (топ-3) до проверки |
| `citation_mode` | `grounded`, `no_rule_needed_clarification`, `missing_source_clarification` |
| `llm_status` | `generated`, `external_processing_disabled`, `irrelevant_citation`, `unknown_citation`, `unverified_quote`, `unsafe_draft`, `rules_not_loaded`, `gemini_timeout` / `llm_quota_exceeded`, `request_deadline_exceeded` и др. |
| `draft_origin` | `assistant_edited_template` — текст собран из проверенных шаблонов |
| `final_draft_checked` | итоговый текст повторно проверен на ссылки и опасные обещания |
| `duplicate_of` | идентификатор исходного обращения при дубликате |
| `usage`, `estimated_paid_cost_usd`, `cost_usd` | токены и стоимость; `cost_usd: null` — стоимость неизвестна, а не нулевая |
| `native_speaker_reviewed` | всегда `false`, пока носители не оценили текст |
| `confidence_target`, `calibration` | что именно оценивает `confidence` и статус калибровки (`awaiting_independent_labels`) |
| `request_budget_ms`, `deadline_exceeded`, `storage_status`, `dedup_status` | диагностика бюджета времени |

### Ошибки

| Код | Когда | Тело |
| --- | --- | --- |
| `400` | невалидный JSON или поля: нет `kind`, пустое сообщение игрока, `attachments` вне 0–100, > 50 сообщений, > 20 000 символов, неверный `created_at` | `{"error":"…"}` на русском |
| `408` | тело запроса читалось дольше лимита | `{"error":"Превышено время чтения запроса"}` |
| `413` | тело больше 100 КБ | `{"error":"Запрос слишком большой"}` |
| `415` | не `application/json` | `{"error":"Ожидается application/json"}` |
| `500` | внутренняя ошибка | обобщённое сообщение без деталей |

Недоступность корпуса, модели, квоты или дедупликации **не приводит к ошибке**: возвращается `200` с безопасным черновиком, `needs_human: true` и причиной в `analysis.llm_status`.

## Очередь

### `GET /api/tickets`

```json
{ "records": [ { "id": "…", "version": 1, "status": "open", "draft": "…", "input": {}, "result": {}, "history": [] } ], "cursor": null }
```

Страница из 50 записей, новые сверху. `cursor` — токен следующей страницы или `null`.

### `POST /api/tickets`

Принимает то же тело, что `/triage`, выполняет триаж, дедупликацию по сохранённым обращениям и сохраняет запись. Ответ `201` — запись целиком.

### `POST /api/tickets/{id}`

```json
{
  "action": "escalate",
  "version": 3,
  "draft": "Здравствуйте! …",
  "reviewed": false,
  "escalation": { "team": "Старшие администраторы", "assignee": "Смена 2", "reason": "Спорные доказательства" }
}
```

| `action` | Требования | Результат |
| --- | --- | --- |
| `save` | `version`, `draft` 1–8 000 символов | сохраняет правку, статус `open` |
| `approve` | `reviewed: true` | статус `approved` |
| `escalate` | `escalation.team`, `.assignee` (≤ 160), `.reason` (≤ 2 000) | статус `escalated` |
| `reopen` | `version`, `draft` | статус `open`; снимает эскалацию и квитанцию |
| `send_test` | статус `approved`, `draft` равен подтверждённому | квитанция `delivery` |

| Код | Причина |
| --- | --- |
| `400` | неизвестное действие, пустой или слишком длинный черновик, нет проверки, нет полей эскалации |
| `401` | нет аутентифицированного пользователя |
| `404` | обращение не найдено |
| `409` | устаревшая версия или конфликт записи — обновите очередь; либо действие над закрытым обращением без `reopen` |

### `POST /api/test-delivery`

```json
{ "ticket_id": "<внутренний id>", "version": 2, "text": "<подтверждённый текст>" }
```

Ответ: `{ "mode": "test", "delivered_to_player": false, "receipt": { … }, "record": { … } }`. Вызов **не обращается к игре**; он сохраняет квитанцию в записи. Повтор с тем же текстом возвращает ту же квитанцию.

## База знаний

### `GET /api/knowledge?q=…&section=…`

| Параметр | Описание |
| --- | --- |
| `q` | запрос ≤ 1 000 символов; без `q` возвращаются **все** 280 фрагментов |
| `section` | точное название раздела для фильтрации |

```json
{
  "loaded": true,
  "documents": 280,
  "sections": 11,
  "section_names": ["…"],
  "total_matched": 280,
  "sources": [ { "id": "30:2.1:0", "ref": "2.1", "section": "Общие правила игры", "title": "…", "text": "…" } ]
}
```

При запросе сначала идут точные вхождения подстроки, затем результаты BM25.

### `GET /api/corpus`

```json
{ "loaded": true, "sections": 11, "documents": 280, "llm_configured": true, "external_enabled": true, "model": "…" }
```

Секреты и ключи не возвращаются.

### `POST /api/corpus`

Заголовок `x-rag-admin-token: <RAG_ADMIN_TOKEN>`, тело — объединённый JSON `{ rules, taxonomy }` ≤ 2 МБ. Коды: `200` загружено, `400` неверный корпус, `401` нет или неверный токен, `413` слишком большой, `503` хранилище недоступно. Скрипт `scripts/upload-corpus.mjs` отправляет корпус, не сохраняя доступы.

## Примеры вызовов

```sh
# триаж
curl -s -X POST http://127.0.0.1:4173/triage -H "Content-Type: application/json" \
  -d '{"kind":"report","messages":[{"role":"player","text":"Оплатил донат, деньги списались, но в игре ничего не пришло"}]}'

# вся база знаний, раздел «Правила жалоб»
curl -s "http://127.0.0.1:4173/api/knowledge?section=%D0%9F%D1%80%D0%B0%D0%B2%D0%B8%D0%BB%D0%B0%20%D0%B6%D0%B0%D0%BB%D0%BE%D0%B1"

# статус корпуса
curl -s http://127.0.0.1:4173/api/corpus
```

Ожидаемый ответ на платёж: `report.payment`, `p0`, `needs_human: true`, черновик просит дату покупки и чек, предупреждает не отправлять пароль и данные карты и **не обещает возврат**.

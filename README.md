# Grand Support Copilot — интерфейс

Статический прототип рабочего места администратора. Все обращения синтетические. Сервер триажа и отправка сообщений пока не подключены.

Локальный запуск: `python -m http.server 4173 --directory dist` из этой папки.

Возможности: поиск, фильтры очереди, карточка обращения, редактирование черновика, просмотр оснований, подтверждение и эскалация в деморежиме, история. Состояние сохраняется в localStorage текущего браузера. Два фрагмента правил взяты из предоставленного rules.json; это не полный индекс RAG. Уверенность — фиксированное демонстрационное значение.

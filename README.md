# Grand Support Copilot

Автономный HTTP-сервис и рабочее место администратора для кейса 03 Decentrathon 6.0.

## Запуск

Требуется Node.js 22.13+ и Python 3 для подготовки архива. Из папки `support-copilot`:

```sh
npm ci
python scripts/prepare-data.py ../Данные/grand-support-copilot-handout-2026-10-27.tgz
npm run dev -- --host 127.0.0.1 --port 4173
```

Откройте `http://127.0.0.1:4173`. Локальное R2-хранилище и опубликованное R2 различаются. Веб-сервис получает корпус через защищённый `POST /api/corpus`; локальный пакетный запуск читает `.private/corpus.json`. Инструкция импорта и Gemini — в [GEMINI_SETUP.md](GEMINI_SETUP.md). Отсутствующий корпус отображается как ошибка конфигурации с безопасным резервным ответом.

## Обработка (`POST /triage`)

`POST /triage`, `Content-Type: application/json`:

```json
{"kind":"complaint","messages":[{"role":"player","text":"Игрок оскорбляет меня в чате, сервер 4","attachments":2}]}
```

Возвращает поля контракта ТЗ: `lang`, `category`, `priority`, `is_spam_or_duplicate`, `extracted`, `draft_reply`, `needs_human`, `confidence`, `reasons`; дополнительно `analysis` и `latency_ms`. Цитаты представлены как `Общие правила игры § 2.1`, поскольку номера пунктов повторяются в разных разделах. Уникальные идентификаторы фрагментов и первоисточники находятся в `analysis.cited_sources`.

Поддерживается исходная схема датасета: `images_count`, `reported_nick`, `rule_refs_raw`, `reporter_hash`, `reported_hash`, `created_at`, `server`. Сообщения `admin`, вердикты и наказания исключаются до анализа (`lib/input.mjs`). Указанный игроком пункт не считается истинным. Вложения не просматриваются.

RAG: BM25 с игровыми синонимами и расширением по категории, все 11 разделов правил, 280 фрагментов. Gemini 3.5 Flash-Lite получает top-3 релевантных фрагментов и компактную JSON-схему (`lib/gemini-wire.mjs`) с кэшированием верифицированных ответов (`lib/generation-cache.mjs`). На выходе проверяются схема, категория канала, ссылки, дословные цитаты и опасные обещания. Правила и шаблоны не доказывают факт нарушения.

Платежи, аккаунты, апелляции и жалобы на администрацию передаются человеку независимо от решения модели (`lib/policy.mjs`). Автоматические ответы разрешаются только для безопасного уточнения или подтверждённой инструкции при достаточной оценке.

## Приватность и Gemini Free

Ввод без `data_mode:"synthetic"` обрабатывается локально и не передаётся Google. Gemini Free вызывается только для отмеченных синтетических примеров. API-ключ хранится как секрет сервера и в игнорируемом `.env.local`. Данные хакатона и производные выборки исключены из Git (`.gitignore`).

Бесплатная квота зависит от проекта Google. Автоматического перехода на платную модель нет. Возвращаются токены и оценка стандартной платной стоимости (`lib/usage.mjs`). [Условия Google](https://ai.google.dev/gemini-api/terms), [тарифы](https://ai.google.dev/gemini-api/docs/pricing).

## Очередь и обратная связь

Обращения, черновики, решения и предыдущие версии текста хранятся в приватном R2 (`lib/ticket-store.mjs`). Правки переживают перезагрузку страницы. Конкурирующие записи защищены ETag и версией; при конфликте нужно обновить очередь. Подтверждение требует явной проверки администратором. Кнопка не отправляет сообщение в игру: боевые API по ТЗ отсутствуют.

`GET/POST /api/tickets`, `POST /api/tickets/:id` — очередь и действия `save`, `approve`, `escalate`, `reopen`. История сохраняет исходный и исправленный текст как обучающий сигнал. После трёх подтверждённых ответов одной категории интерфейс предлагает кандидата в шаблоны.

Для дедупликации (`lib/dedup.mjs`, `lib/dedup-store.mjs`) используются анонимный ID заявителя и время: одна проблема, один игрок, окно один час, сходство токенов ≥ 0.75. Онлайн-контекст хранит до 100 обращений на игрока за последний час обработки; пакетный режим использует скользящее окно из 10 000 записей.

## Пакетный запуск, демо и оценка

```sh
# Пакетное предсказание на валидационной выборке
make predict IN=.private/tickets_valid.jsonl OUT=.private/pred-valid.jsonl
# Или напрямую через Node.js (если make не установлен в системе):
node scripts/predict.mjs .private/tickets_valid.jsonl .private/pred-valid.jsonl

# Демонстрационный прогон на синтетических примерах (RU/KK/UZ, платежи, читы, дедупликация)
node scripts/predict.mjs examples/synthetic-tickets.jsonl .private/pred-synthetic.jsonl

# Тесты и проверка типов
npm test
npm run typecheck

# Оценка метрик и живой smoke-тест
node scripts/evaluate.mjs .private/tickets_valid.jsonl .private/evaluation-valid.json
node scripts/evaluate.mjs .private/review-check.jsonl .private/check-after.json
node scripts/smoke-live.mjs
```

Одна строка входа соответствует одной строке выхода. Ошибочная запись возвращает `line` и `error`, завершение — с ненулевым кодом. Вход и выход не могут быть одним файлом.

## Используемые источники и лицензии

- **Node.js / Web Standard APIs** — среда выполнения и криптография (MIT).
- **Next.js / React / Tailwind CSS / Lucide / Radix UI** — веб-интерфейс администратора (MIT).
- **Cloudflare Workers / Wrangler / Miniflare** — серверная платформа и локальная эмуляция R2 (Apache-2.0 / MIT).
- **Google Gemini API (`gemini-3.5-flash-lite`)** — опциональная внешняя генерация для синтетических данных по [условиям Google API](https://ai.google.dev/gemini-api/terms).
- **Данные кейса Grand Mobile (`rules.json`, `taxonomy.json`, `tickets_valid.jsonl`)** — проприетарные материалы Decentrathon 6.0, используются строго локально/приватно, не публикуются в репозитории и подлежат удалению в течение 14 дней после объявления результатов.

Подробный отчёт с метриками, примерами черновиков, стоимостью и латентностью — в [REPORT.md](REPORT.md).

## Работа администратора и тестовая доставка

Очередь поддерживает совместные фильтры по приоритету, языку, категории и серверу. Карточка показывает подсказки следующего действия; это рекомендации для проверки, а не подтверждение полноты данных или содержимого вложений. Несохранённые черновики отмечены над рабочей областью, сохраняются при переходах внутри вкладки и вызывают предупреждение браузера при закрытии. После перезагрузки несохранённый текст не восстанавливается.

Передача специалисту требует команды, ответственного (имя или смена) и причины. Это запись в общей очереди, без внешнего уведомления или проверки имени по кадровому справочнику. Новые события содержат автора из удостоверенной Sites учётной записи; для старых записей автор неизвестен. История внутри карточки показывает время, автора и обе версии изменённого текста. Возврат в очередь снимает текущую передачу, сохраняя историю.

`POST /api/test-delivery`, `Content-Type: application/json`:

```json
{"ticket_id":"<внутренний id обращения>","version":2,"text":"<подтверждённый текст>"}
```

Тестовый адаптер не вызывает игровой сервер. Принимает только обращение в статусе `approved` и текст, совпадающий с подтверждённым. Возвращает `mode: "test"`, `delivered_to_player: false`, `receipt` и обновлённый `record`. Квитанция сохраняется в приватном R2 в записи обращения с историей и защитой ETag. Повторный запрос с тем же текстом для уже отправленного подтверждённого ответа возвращает ту же квитанцию без нового события; при конкурентном конфликте нужно повторить запрос. Возврат в очередь очищает текущую квитанцию, сохраняя её в истории, и требует нового подтверждения перед следующей тестовой отправкой. Реальная доставка требует отдельной интеграции с игровым API.

На опубликованном общедоступном демо чтение очереди доступно посетителям, а создание, изменение и тестовая отправка требуют входа через ChatGPT. Работающие с демо пользователи после входа используют общую очередь. Без входа API записи возвращают 401, интерфейс предлагает штатный вход Sites. Это демонстрационная модель доступа; перед подключением реальной игры потребуется ограничить круг администраторов и доступ к обращениям.

# Gemini и RAG

Полный корпус правил импортируется отдельно в приватное R2-хранилище; исходные файлы и индекс отсутствуют в Git и клиентской сборке. Индекс: 11 разделов, 280 фрагментов из 266 пунктов и RP-терминов. Поиск: BM25 и расширение запросов игровыми синонимами на ru/kk/uz/en. Это retrieval-augmented generation без внешней службы embeddings. Качество retrieval и генерации на валидации ещё не измерено.

Модель по умолчанию `gemini-3.5-flash-lite`. По официальной странице Google есть Free Tier, но реальные квоты зависят от проекта. Код не переключается на платные модели; включённый биллинг Google всё равно может приводить к начислениям — тариф не определяется по API-ключу автоматически.

В настройках окружения сайта задайте секрет `GEMINI_API_KEY`. Не размещайте ключ в исходниках или браузере. `GEMINI_MODEL` и `GEMINI_EXTERNAL_ENABLED=true` уже настроены. После изменения ключа нужно повторно развернуть сохранённую версию для применения окружения.

Для локальной пакетной обработки создайте игнорируемый `.env.local`:

```
GEMINI_API_KEY=your-key
GEMINI_MODEL=gemini-3.5-flash-lite
GEMINI_EXTERNAL_ENABLED=true
CORPUS_PATH=.private/corpus.json
```

Запуск `node scripts/predict.mjs input.jsonl output.jsonl` или `make predict IN=input.jsonl OUT=output.jsonl`. Для внешнего вызова у синтетической записи должно быть `data_mode: "synthetic"`. Данные хакатона не отправляются в Gemini Free автоматически: Google запрещает конфиденциальные и персональные данные в unpaid services. Для реальных закрытых обращений используйте допустимый по условиям обработки тариф или локальную модель после согласования.

Пайплайн: валидация → нормализация → поиск top-6 → редактирование идентификаторов и контактов → Gemini structured JSON → проверка схемы, источников и дословных цитат → обязательная эскалация. Редактирование контактов не гарантирует удаление всей конфиденциальной информации: пользователь вводит только синтетические примеры.

Проверки цитат доказывают существование источника и наличие цитаты, но не гарантируют полную смысловую верность. Релевантность ограничена retrieval и инструкцией модели; нужен отдельный аудит. Оценка уверенности не калибрована. Все исходные правила хранятся и отображаются с разделом, номером и уникальным id.

При отсутствии ключа/корпуса, 429, таймауте 4,2 с, неполном JSON, неизвестной цитате или запрещённом обещании сервис возвращает безопасный резервный черновик с `needs_human: true` и явным `analysis.llm_status`. p95 ≤ 5 с пока не подтверждён нагрузочным тестом. usageMetadata возвращается, стоимость неизвестна без тарифа проекта.

`GET /api/corpus` — статус без секретов. `GET /api/knowledge?q=...` — поиск. `POST /api/corpus` — импорт только с секретным `x-rag-admin-token`; данные передаются в теле. `scripts/upload-corpus.mjs` получает временные доступы через stdin и не сохраняет их. RAG_ADMIN_TOKEN используется только для импорта. Не хранить токены и датасеты в Git.

Документация: https://ai.google.dev/gemini-api/docs/pricing и https://ai.google.dev/gemini-api/terms.

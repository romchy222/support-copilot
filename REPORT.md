# Проверка решения — 30 октября 2026

## Что реализовано

- HTTP `POST /triage`, проверка и ограничение размера входа.
- Пакетный `make predict`, адаптер исходной схемы, исключение утечки ответов администраторов.
- Нормализация казахских замен cp1251, язык и классификация, извлечение фактов.
- RAG по полному корпусу правил: разделы и уникальные фрагменты, Gemini structured JSON, проверка цитат, безопасный резервный ответ.
- Независимые от LLM правила обязательной эскалации.
- Приватная серверная очередь, редактирование, подтверждение и эскалация, история и обучающая обратная связь, защита от конфликтов.
- Дедупликация в окне одного часа при наличии идентификатора игрока и времени; поиск по правилам и экспорт результата.
- Кандидаты в шаблоны по повторяющимся подтверждённым категориям.

Для завершившегося ответа: 1 444 входных и 243 выходных токена. По стандартным платным ставкам Gemini 3.5 Flash-Lite ($0,30 / $2,50 за миллион токенов) оценка составляет **$0,0010407**, без инфраструктуры. На бесплатном тарифе токены бесплатны в пределах квоты, но наличие тарифа Free не устанавливается по ключу. При таймауте фактическая стоимость неизвестна. Источник ставок: [официальная страница Google](https://ai.google.dev/gemini-api/docs/pricing), проверено 30.10.2026.

Ограничение p95 ≤ 5 с для боевого HTTP-сервиса под нагрузкой пока **не подтверждено**. Сервис ограничивает время ожидания модели оставшимся бюджетом; это не гарантирует SLA провайдера. Частые таймауты бесплатного API — существенная текущая слабость.

## Что нужно для окончательной оценки жюри

1. Независимо разметить категории и приоритеты в `.private/review-set.jsonl` и пересчитать метрики. Нельзя подменять их вердиктом или ответом администратора.
2. Провести слепую оценку черновиков администраторами и носителями kk/uz. Для этого сохраняются черновик и источники, но оценки ещё не получены.
3. Измерить p95 HTTP под заданной нагрузкой и проверить квоты конкретного проекта Gemini. Free API не обеспечивает стабильную доступность генерации.
4. Согласовать допустимый способ обработки конфиденциальных обращений: локальная модель или подходящие условия внешнего провайдера. Реальные обращения в Gemini Free автоматически не отправляются.

Внешняя отправка сообщений игрокам не реализована: Grand Mobile не предоставляет боевой API, а интеграция после хакатона выполняется студией. Кнопки интерфейса фиксируют решения администраторов, не изображают доставку игроку.

# Grand Support Copilot — интерфейс

Рабочее место администратора с серверным `POST /triage`. Восемь исходных обращений синтетические; кнопка «Новое обращение» отправляет введённый текст на сервер и показывает рассчитанный результат.

Локальный запуск: `npm run dev -- --host 127.0.0.1 --port 4173`. Откройте `http://127.0.0.1:4173/index.html`.

Возможности: поиск, фильтры, карточка обращения, редактирование черновика, просмотр оснований, подтверждение и эскалация в деморежиме, история. Правки и решения сохраняются в localStorage. Новые обращения живут только до обновления страницы. Отправка игрокам не подключена.

Базовый алгоритм: нормализация казахских замен, эвристики языка и классификации, лексический поиск по минимальной базе правил и безопасные шаблоны на ru/kk/uz/en/es/pt. Полный RAG и LLM не подключены. Два фрагмента правил доступны в демонстрации базы знаний, в поиске используется один релевантный пункт об оскорблениях. Уверенность не калибрована; фиксированные значения исходных примеров демонстрационные. Качество на датасете ещё не измерено. Стоимость внешних API равна нулю, инфраструктура отдельно.

Запрос: `{"kind":"report","messages":[{"role":"player","text":"Оплатил донат, деньги списались","attachments":0}]}`. Ответ соответствует основным полям ТЗ, дополнен `analysis` и `latency_ms`. Роли admin и поля исхода исключаются из анализа. Дедупликация по пользователю и временному окну пока не реализована; флаг выявляет только узкий случай повторного флуда.

Пакетная обработка: `make predict IN=tickets.jsonl OUT=pred.jsonl` либо `node scripts/predict.mjs tickets.jsonl pred.jsonl`. Проверки: `node --test tests/triage.test.mjs`.

Датасеты и производные выборки не добавлять в репозиторий. Используются только синтетические тесты.
